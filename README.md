# Auto VPN Subscription

- Протоколы: VLESS, VMess, Trojan, Hysteria2
- Без Украины
- Обновление каждые 6 часов

## Получить подписку

1. Зайди в **Actions** → последний запуск **Update VPN**
2. Пролистай вниз до **Artifacts**
3. Скачай `vpn-configs.zip`
4. Разархивируй → `configs.txt` — твоя подписка

## Использовать в Karing

1. Открой `configs.txt` текстовым редактором
2. Скопируй всё содержимое
3. В Karing: **Подписки** → **Импорт из буфера**
